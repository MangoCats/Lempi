Fleet sync [SPEC-STAR-120]

The desktop is the source of truth. A sync takes each node's edits, merges them here, and sends the result back out — by signed request to each node's own player, which applies it itself and is not stopped. Nothing is sent until every conflict below has a verdict, the patches are proven and each node has been rehearsed clean [SPEC-STAR-116].
