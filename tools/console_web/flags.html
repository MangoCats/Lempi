Apply pending edits to this library

Lempi's editor records a draft and changes nothing else: an edit is not in the library, and cannot be pushed anywhere, until it is folded in here. This runs the same apply_boundary_reviews.py / apply_reviews.py you would otherwise type, as an ordinary job, so who may write the library has not changed -- only how hard it is to do it deliberately. Sync with a remote

Pull brings {{PEER_NAME}}'s own flags here, resolved by audio content rather than a local number — a flag on a recording or passage this library doesn't have yet is counted and reported, not silently dropped. It reads only the flags themselves over ssh, never a copy of the whole library, so it's quick even over {{PEER_NAME}}'s own slow WiFi. Push lands whatever identification/boundary/artist edits have accumulated here since the last push, and clears the flags they answer — batched, on request only: it briefly stops and restarts each node's own player, so it never runs on its own. It reads only what the comparison needs, one small ssh query per change, never a copy of the whole library [SPEC-DF-120]; a node that is split is patched through its listener half with the catalogue attached, so each statement lands in the right file. Sync preferences reconciles each side's own hand-tuned artist/recording rotation, recovery and restraint — whichever side edited a given one more recently wins, and only the ones that actually differ move, in either direction; an artist or recording either side's library doesn't have at all is left alone rather than guessed at.
