Build a bundle for a remote Lempi

A GUI over export_bundle.py — audio plus its derived facts for whatever matches below, never the database itself. This carries new music to a Lempi that has none of it; a correction to a recording or passage both installations already have is a different tool (tools/export_changes.py).

Deploy — nothing here runs anything on another machine

Vipunen never reaches another host on its own. This opens an ordinary terminal on this machine and shows the commands as plain text — copy them in, or type your own; either way you see exactly what runs before it does.
