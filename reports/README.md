# `reports/`

Standalone, self-contained investigation reports (rendered HTML), kept for the record after the work they document is done. Not regenerated on build, not read by any tool — historical, like `docs/LOG001-extraction-iterations.md`, just one artifact per file instead of one running log.

Reviews of the whole repository are kept here too, one dated Markdown page each (`review-YYYY-MM-DD.md`): a snapshot of what was found then, not a register kept current -- the open items they name live on in the documents they cite. An audit of one question is kept the same way (`integrity-audit-2026-10-14.md`, its plan in GUIDE038).
